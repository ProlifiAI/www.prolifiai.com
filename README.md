# Prolifi website

Marketing site for Prolifi, rebuilt from the Figma export in `assets/references/prolifi-current.png`.

Stack: Next.js 15 (App Router), React 19, Tailwind CSS v4, Motion, Geist, Phosphor icons, zod.
Selected Magic UI components (Blur Fade, Marquee, Dot Pattern, Magic Card) were added through the
official registry (`npx shadcn add https://magicui.design/r/<name>.json`) and live in `src/components/ui`.
Dot Pattern and Magic Card were adapted; the reason is noted at the top of each file.

## Run

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
npm start            # serve the production build
npm run lint
npm run typecheck
```

## Deploy (Vercel or any Node host)

1. Push this folder to a Git repository and import it in Vercel (framework preset: Next.js).
2. Set the environment variables from `.env.example`:
   - `NEXT_PUBLIC_SITE_URL`: the production domain, used for canonical URLs, Open Graph and the sitemap.
   - `RESEND_API_KEY`, `CONTACT_FROM_EMAIL`: enquiry delivery via [Resend](https://resend.com) to
     `info@prolifiai.com` (the recipient is fixed in `src/content/site.ts`). The sender domain must be verified in Resend.
   - `GOOGLE_SITE_VERIFICATION` (optional): Search Console HTML-tag token, if you do not verify by DNS.
   - `NEXT_PUBLIC_CONTACT_EMAIL` (optional): a public address shown on the contact page and in error messages.
3. Deploy. Without the Resend variables, `/api/contact` returns 503 in production and the form says the
   enquiry could not be sent; it never shows a false success.

## Live setup (as configured)

- Production: https://www.prolifiai.com (Vercel project `prolifi-ai/prolifi-website`). `prolifiai.com` redirects to `www`.
- DNS at Namecheap: `@` A records `216.198.79.1` and `64.29.17.1`; `www` CNAME to the Vercel target shown in the
  project's Domains settings.
- Mailboxes: Namecheap Private Email (MX `mx1/mx2.privateemail.com`). Enquiries go to `info@prolifiai.com` via
  Resend. Resend can only deliver to that address once `prolifiai.com` is verified in Resend (DKIM/SPF records added at
  Namecheap) and `CONTACT_FROM_EMAIL` uses that domain, e.g. `Prolifi Website <website@prolifiai.com>`.
  `CONTACT_TO_EMAIL` is no longer read.
- SEO: `robots.txt` and `sitemap.xml` are generated by `src/app/robots.ts` and `src/app/sitemap.ts`. Per-page titles,
  descriptions, canonicals and Open Graph come from `pageMetadata()` in `src/lib/seo.ts`; each route has its own
  `opengraph-image.tsx`; Organization + WebSite JSON-LD is in `src/app/layout.tsx`.
- Redeploy after changing environment variables: `npx vercel deploy --prod` (or `scripts/deploy.ps1`).

## Motion and visual system

- Brand colours: navy `#0E3062`, yellow `#F4C430`, white, neutral `#F7F8FA` (tokens in `src/app/globals.css`).
- Reveals: `Reveal` / `BlurFade` in `src/components/ui/blur-fade.tsx` (fade-up, fade-in, slide-left, slide-right,
  blur-up). Shared timings live in `src/lib/motion.ts`. Content reveals once and stays.
- Parallax: `Parallax`, `ParallaxImage` and `useParallaxY` in `src/components/motion/parallax.tsx` (Motion `useScroll`,
  transform only, reduced on phones, off for reduced motion).
- Liquid glass: `GlassGradientBackground` (CSS only) and `.glass-surface`.
- Hero video: `public/video/hero-background.mp4` (Google Flow clip, re-encoded to 1920x1080 H.264, 8 s, about
  1.2 MB) with `public/video/hero-poster.jpg`. Reduced-motion and data-saver visitors get the poster only.
- Inner-page hero videos (`pageVideos` in `src/components/motion/brand-video-background.tsx`), each 1920x1080 H.264,
  10 s, about 1 MB, with a poster: `about-hero`, `services-hero`, `pricing-hero`, `contact-hero` (Contact sidebar).
  To replace one, encode the new clip to the same filename (no audio, `-movflags +faststart`) and update its poster.
- Buttons: `src/components/button.tsx`. Colour ball, label roll and arrow share `--duration-button-reveal` and
  `--ease-button`; replacement labels live in `hoverLabels` in `src/content/site.ts`.
- Founders: `src/components/founders.tsx`; data and links in `src/content/company.ts`. Portraits are transparent
  cut-outs from `assets/references/founders-reference.webp`, placed over a CSS gradient sampled from that design.

## Editing content

Everything editable is in `src/content`:

| File | What it controls |
| --- | --- |
| `site.ts` | Name, SEO description, navigation, CTA labels, social links, footer legal line |
| `services.ts` | BUILD / LAUNCH / SCALE pillars (focus line, core message, services), contact options, the process steps |
| `pricing.ts` | Packages, prices (USD), inclusions, comparison table, quoted work |

## Needs confirmation before launch

These items are deliberately hidden or worded conservatively until someone at Prolifi confirms them:

- **Impact metrics** (`impactMetrics` in `src/content/company.ts`): "10+ Websites Delivered" and "4.5/5 Client Rating"
  have `verified: false`. They show in local development with a "Needs confirmation" tag and are left out of
  production builds. Set `verified: true` once confirmed (and use only one of 4.5/5 or 95%).

- **Prices**: Starter $450, Professional $900, Custom "Contact us", all USD, set by Prolifi in October 2026.
  Inclusions were lightly reworded from the old design: "SLA-backed delivery timelines" became
  "Agreed delivery timelines", "white-labelling" and "Complete digital transformation solution" were dropped.
- **Not carried over**: "Money-back guarantee", "30-day free trial", "Upgrade or cancel anytime", the ".65" cents.
- **Testimonials**: the three reviews in the old design look like template placeholders. They are stored with
  `approved: false`; the section appears automatically once one is approved.
- **Case studies**: none were confirmed, so the "Selected work" section is hidden until `projects` has approved entries.
- **Digital product development**: listed under SCALE but `available: false` until delivery capability is confirmed.
- **Process and expectations copy** (written proposal before work starts, review points, handover): confirm it
  matches how the team works.
- **Social links, contact email, company registration line**: empty, so nothing renders. Add real values.
- **Logo**: the official logo is in `public/brand` (transparent PNGs cut from the supplied 2000 px artwork; favicon in
  `src/app/icon.png`). If you have an SVG version, it would be sharper still.
- **Team photos**: Damilola's and Deborah's photos are only 360 px and 299 px wide and look soft on large screens.
  Replace them with higher-resolution versions using the same filenames.
- **Photography**: the three work photos are cropped from the Figma export (about 770 px wide). Higher-resolution
  originals, or real Prolifi project screenshots, would noticeably improve the hero and service pages.

## Audit of the previous design (summary)

- Template placeholder copy throughout ("Stellar is more than just a SaaS...", A&O Essentials FAQs, nutrition
  statistics, "The Landscaper's Coach" footer, "Registered in England & Wales 00000000").
- Unverified proof: fabricated-looking hero metrics ($897,543, 12K customers), testimonials, guarantees.
- Hero did not say what Prolifi does or for whom; five different labels for the same "contact" action.
- Repeated "Provide Powerful Solutions At All Times" headline across sections and pages.
- Contact form asked for revenue and team size but not the project or budget, and had no visible validation states.
- Services were described by placeholder process text rather than problems, audiences and deliverables.

Retained: navy and yellow palette, the pill buttons with an arrow puck, the yellow "Ready to grow your business?"
band, the oversized PROLIFI footer wordmark, the founders section, the three-tier pricing and comparison table.
